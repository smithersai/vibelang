# Historical compiler prototypes

These experiments record the state of the compiler on 2026-10-16, when
they used Effect 4.0.5. The `.es` sources and `ES` diagnostics predate
the current `.vibe` language. The build graph does not use these compilers
and a fresh checkout does not provide the dependencies they used.

[ESC findings](esc/FINDINGS.md) and [single-pass results](single-pass/RESULTS.md)
record measurements from that environment.
