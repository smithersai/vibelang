# Terminal

`Terminal` is Effect's interactive input and output service. Use it for prompts and line input, provide a runtime terminal layer, and handle a user's quit request as a typed error where it fits.

## Requesting terminal services

```vibe
effect function dimensions() {
  const terminal = try Terminal.Terminal
  return { columns: try terminal.columns, rows: try terminal.rows }
}
// { columns: number; rows: number }!!Terminal.Terminal
// Output: {"columns":80,"rows":24}
```

`try Terminal.Terminal` gets the service implementation; the key itself is `Terminal.Terminal`. `columns`, `rows`, and `readLine` hold Effect values, so run them with `try terminal.columns` or `try terminal.readLine`. `display(text)` returns an Effect that also needs `try`.

## Writing standard output

```vibe
// main.vibe
import * as NodeRuntime from "@effect/platform-node/NodeRuntime"
import * as NodeTerminal from "@effect/platform-node/NodeTerminal"

effect function main() {
  const terminal = try Terminal.Terminal
  try terminal.display("Package prepared.\n")
}

NodeRuntime.runMain(Effect.provide(main(), NodeTerminal.layer))
// Output: Package prepared.
```

`display` writes the string you pass; add a newline to complete a line. Output can fail with `PlatformError`. The Node terminal layer supplies the service, so the application needn't call native standard-output APIs.

## Reading standard input

```vibe
effect function askName() {
  const terminal = try Terminal.Terminal
  try terminal.display("Your name: ")
  const name = try terminal.readLine
  try terminal.display(`Hello, ${name.trim() || "visitor"}.\n`)
}
// void!(Terminal.QuitError | PlatformError.PlatformError)!Terminal.Terminal
// Output: Your name:
// Output: Hello, Ada.
```

`try terminal.readLine` waits for a line and returns its text. Reads and displays run in order, so the prompt appears before input is requested. When line input isn't enough, low-level `readInput` exposes scoped input events.

## Handling terminal quit errors

```vibe
effect function askNameOrQuit() {
  return askName() catch effect (error) => match (error) {
    when { _tag: "QuitError" }: undefined;
    default: throw error;
  }
}
// Output: Your name:
// Output: quit handled
```

`QuitError` signals that terminal input ended. Handle it when end-of-input counts as normal completion, and rethrow unrelated failures. In Effect 4.1.0, the Node adapter's `readLine` raises it on end-of-input, including Ctrl+D at a terminal. `readLine` leaves the terminal out of raw mode, so Ctrl+C interrupts the program. The quit keys configured by `NodeTerminal.make` govern `readInput`.

A host SIGINT or SIGTERM is a separate termination path: the runner interrupts the program, bypassing a `catch` expression, and runs cleanup. While the Node line reader holds the terminal in raw mode, Ctrl+C raises no host signal.

## Building an interactive guessing program

```vibe
// guessing.vibe
function parseGuess(input: string) {
  const text = input.trim()
  const number = Number(text)
  return /^\d+$/.test(text) && Number.isInteger(number) &&
    number >= 1 && number <= 20
    ? Option.some(number)
    : Option.none<number>()
}

effect function game() {
  const terminal = try Terminal.Terminal
  const secret = try Random.nextIntBetween(1, 20)
  try terminal.display("Guess an integer from 1 to 20. You have five guesses.\n")

  let attempts = 0
  while (attempts < 5) {
    try terminal.display(`Guess ${attempts + 1}: `)
    const guess = parseGuess(try terminal.readLine)
    if (Option.isNone(guess)) {
      try terminal.display("Enter a whole number from 1 to 20.\n")
      continue
    }
    attempts++
    if (guess.value === secret) {
      try terminal.display("Correct!\n")
      return
    }
    try terminal.display(guess.value < secret ? "Try higher.\n" : "Try lower.\n")
  }
  try terminal.display(`The answer was ${secret}.\n`)
}
// void!(Terminal.QuitError | PlatformError.PlatformError)!Terminal.Terminal

export effect function main() {
  return game() catch effect (error) => match (error) {
    when { _tag: "QuitError" }: undefined;
    default: throw error;
  }
}

// Output: Guess an integer from 1 to 20. You have five guesses.
// Output: Guess 1:
// Output: Enter a whole number from 1 to 20.
// Output: Guess 1:
// Output: Try higher.
// Output: Guess 2:
// Output: Try lower.
// Output: Guess 3:
// Output: Correct!
```

The random service picks the secret once per game, both endpoints included. Invalid input repeats the prompt without using a guess; valid input increments the attempt count. The loop stops on success, after five valid guesses, or on a quit request; the runner still reports unexpected output failures.

## Coming from Effect

`try terminal.readLine` replaces `yield* terminal.readLine`. Effect functions and loops replace the generator and recursive Effect construction TypeScript uses for this interaction. Keep the runner in its own entry module so tests can import `main` and supply terminal input:

```vibe
// guessing-main.vibe
import * as NodeRuntime from "@effect/platform-node/NodeRuntime"
import * as NodeTerminal from "@effect/platform-node/NodeTerminal"
import { main } from "./guessing.vibe"

NodeRuntime.runMain(Effect.provide(main(), NodeTerminal.layer))
// Output: Guess an integer from 1 to 20. You have five guesses.
// Output: Guess 1: 
```
