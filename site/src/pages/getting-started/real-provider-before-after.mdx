# A Real Provider, Before and After

[Alchemy](https://alchemy.run) deploys cloud resources from Effect programs. Below is one of its AWS resource providers (`RegistryPolicy`, for private Amazon ECR registry permissions) in Alchemy's Effect TypeScript and in VibeLang from the [smithersai/alchemy](https://github.com/smithersai/alchemy/tree/vibe) fork, with the hand edits noted below.

Both listings omit Alchemy's comments and show only `RegistryPolicyProvider`. Elsewhere in the file, VibeLang drops the `effect/Effect` import (already in scope) and imports `../IAM/Policy.vibe` instead of `.ts`; props and doc comments are unchanged.

## Effect TypeScript

From `packages/aws/src/ECR/RegistryPolicy.ts`.

```ts [Effect]
// fragment
export const RegistryPolicyProvider = () =>
  Provider.effect(
    RegistryPolicy,
    Effect.gen(function* () {
      const readPolicy = ecr
        .getRegistryPolicy({})
        .pipe(Effect.catchTag("RegistryPolicyNotFoundException", () => Effect.undefined));

      const toPolicyText = (policy: PolicyDocument | string) =>
        typeof policy === "string" ? policy : stringifyPolicyDocument(policy);

      return {
        stables: ["registryId"],
        read: Effect.fn(function* () {
          const observed = yield* readPolicy;
          if (observed?.policyText === undefined) return undefined;
          return {
            registryId: observed.registryId ?? (yield* AWSEnvironment.current).accountId,
            policy: observed.policyText,
          };
        }),
        list: () =>
          Effect.gen(function* () {
            const observed = yield* readPolicy;
            if (observed?.policyText === undefined) return [];
            return [
              {
                registryId: observed.registryId ?? (yield* AWSEnvironment.current).accountId,
                policy: observed.policyText,
              },
            ];
          }),
        reconcile: Effect.fn(function* ({ news, session }) {
          const desired = toPolicyText(news.policy);

          const observed = yield* readPolicy;
          let registryId = observed?.registryId;
          if (
            observed?.policyText === undefined ||
            normalizePolicyDocument(observed.policyText) !== normalizePolicyDocument(desired)
          ) {
            const put = yield* ecr.putRegistryPolicy({ policyText: desired });
            registryId = put.registryId ?? registryId;
          }
          registryId ??= (yield* AWSEnvironment.current).accountId;

          yield* session.note(registryId);
          return { registryId, policy: desired };
        }),
        delete: Effect.fn(function* () {
          yield* ecr
            .deleteRegistryPolicy({})
            .pipe(Effect.catchTag("RegistryPolicyNotFoundException", () => Effect.void));
        }),
      };
    }),
  );
```

## What changed

| Effect TypeScript | VibeLang |
| --- | --- |
| `Effect.gen(function* () { ... })` | `effect { ... }` |
| `Effect.fn(function* ({ news }) { ... })` | `effect ({ news }) => { ... }` |
| `yield* e` | `try e` |
| `e.pipe(Effect.catchTag("X", () => Effect.void))` | `e catch { when { _tag: "X" }: undefined }` |

Across the provider, 9 `yield*`, 2 `Effect.gen`, 3 `Effect.fn`, and 2 `.pipe` calls disappear: 57 lines vs 58, and 1,436 non-whitespace characters vs 1,302. With concise tagged `catch { when ... }` (VIP-75), unmatched errors rethrow automatically with narrowed residual types—making even single-tag recovery shorter and clearer than `Effect.catchTag`.

## Hand edits

Manual cleanup after automated conversion:

- Replaced `when { _tag: "..." }: try Effect.void` and `try Effect.undefined` with `undefined`.
- Joined `ecr.getRegistryPolicy({})` and `ecr.deleteRegistryPolicy({})` onto one line with their `catch`.
- Removed two `: infer _` return annotations and `mutable` member modifiers emitted by an earlier converter (the fork keeps the two annotations until it upgrades).

## How it was checked

- **Compiler:** Zero diagnostics on this module (the rest of the fork ran on its pinned compiler).
- **Declarations:** Emitted `.d.ts` matches Alchemy's TypeScript output apart from relative import extensions.
- **Tests:** `test/AWS/ECR/RegistryPolicy.test.ts` (deploy, read, redeploy, destroy) passes unchanged against a local ECR/STS stand-in, and fails when a planted fault replaces the delete call.
- **Formatting:** `vibelang-format --check` passes.
