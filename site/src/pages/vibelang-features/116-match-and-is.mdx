# Pattern matching with match and is

`match` picks the first arm whose pattern fits a value. `is` tests a value against one pattern. Both come from the TC39 [pattern matching](https://github.com/tc39/proposal-pattern-matching) proposal (stage 1) and compile to plain conditionals, tested in order. Patterns narrow the subject as their TypeScript counterparts do. Bindings take the types of the values those counterparts extract. An arm can run Effects with `try` inside an effect function or block.

**`match` is exhaustive.** A match without a `default` arm over a finite union, such as a data type's variants, `error` classes or literals, must handle every case, or the compiler reports EK4701: `This match does not handle every case of Delivery: Delivery.Rejected is left.` See [Exhaustiveness](#exhaustiveness).

## match

```vibe
error NotFound { id: string }
error Timeout
error Denied { user: string; reason: string }

type Failure = NotFound | Timeout | Denied

function describe(failure: Failure) {
  return match (failure) {
    when NotFound(let e): `no user ${e.id}`;
    when Timeout: "retry";
    when Denied and { reason: "root" or "admin" }: "denied by policy";
    when Denied: `denied ${failure.user}`;
  }
}
// Output: ["no user 7","retry","denied by policy","denied Ada"]
```

Each arm, `when pattern: expression;`, is tried in order; the first match gives the value. A `default: expression;` arm matches anything and must come last. The value is read once, before the first arm, as `switch` reads its discriminant, so a getter such as `user.role` runs once. `match` is an expression: it can follow `return`, initialize a `const`, or be an argument.

A synchronous `match` introduces no function or Effect boundary in any expression position. An arm may `yield` in an enclosing generator or use `try` in effect code.

An arm is one expression. Use `do { }` for several statements. It gives the block's normal completion value, retaining an earlier value when a later empty block inherits it. Inside `do`, declare variables with `const` or `let`: `var` is `EK1019`, with a quick fix to `let`. `do` introduces no function boundary. A `return`, `break` or `continue` reaches the enclosing function, loop or label. An unlabeled `break` or `continue` in a `do` in a loop head is an error. These rules also apply in nested blocks. A nested function keeps its own declarations and control flow. For example:

```vibe
effect function retryDelay(failure: Failure) {
  return match (failure) {
    when Timeout: do {
      try Console.log("timed out")
      "1 second"
    };
    default: "0 millis";
  }
}
// Output: timed out
// Output: 1 second
// Output: 0 millis
```

A function named `match` still works. Only `match (value) {` followed by `when`, `default`, or `}` starts a match.

## Patterns

| Pattern | Matches | Example |
| --- | --- | --- |
| Literal | An equal string, number, boolean, `null`, or `undefined` | `when 404:` |
| Binding | Anything, and names it with `let` or `const` | `when let other:` |
| Array | An iterable of that length. `...` allows more | `when [let first, ...let rest]:` |
| Object | A value with those properties; `{ let id }` binds `id` | `when { status: 200, let body }:` |
| Matcher | What a class's `Symbol.customMatcher` or another custom matcher accepts | `when NotFound:` |
| Variant | A data type's tag and the fields the object pattern lists | `when { _tag: "Sent", let tracking }:` |
| Extractor | A matcher's values, matched by the list in parentheses | `when Option.Some(let user):` |
| `and`, `or`, `not` | Conjunction, alternative, or negation | `when "a" or "e":` |
| Guard | A condition that is true | `when [let n] and if (n > 0):` |

`var` is not allowed in pattern bindings (`EK0107`).

```vibe
function shape(value: ReadonlyArray<number> | { kind: string; size?: number }) {
  return match (value) {
    when []: "empty";
    when [let only]: `one: ${only}`;
    when [let first, ...let rest]: `${first} then ${rest.length} more`;
    when { kind: "box", let size }: `box of ${size}`;
    when { kind: "point", ...let others }: `point with ${Object.keys(others).length} more keys`;
    default: "other";
  }
}
// Output: ["empty","one: 2","2 then 2 more","box of 5","point with 1 more keys","other"]
```

An object pattern matches only an object or a function, never a primitive, and reads no property of a primitive: `{ length: let n }` does not match a string. It checks only the properties it names, and `...let rest` collects the others. A property that is not a valid name needs quotes, `{ "content-type": let type }`, and a computed key can be a name, `{ [key]: let value }`.

## Option, Exit, Result, and primitives

These matchers compile to the module's own test. A name means what it resolves to. A local binding named `String` or `Option` shadows the built-in or intrinsic. A class pattern naming a `data` declaration or variant is `EK0702`. Until Effect ships custom matchers for Option, Exit, Result, and its tagged errors, VIP-7 keeps these fixed checks without patching Effect at runtime.

| Matcher | Test | Extracts |
| --- | --- | --- |
| `Option.Some`, `Option.None` | `Option.isOption(s) && Option.isSome(s)`, `Option.isOption(s) && Option.isNone(s)` | the value, nothing |
| `Exit.Success`, `Exit.Failure` | `Exit.isExit(s) && Exit.isSuccess(s)`, `Exit.isExit(s) && Exit.isFailure(s)` | the value, the cause |
| `Result.Success`, `Result.Failure` | `Result.isResult(s) && Result.isSuccess(s)`, `Result.isResult(s) && Result.isFailure(s)` | the success, the failure |
| `String`, `Number`, `Boolean`, `BigInt`, `Symbol` | `typeof` or `instanceof` the boxed constructor | the primitive value, unboxed with `valueOf()` for a boxed object |

```vibe
function greeting(name: Option.Option<string>) {
  return match (name) {
    when Option.Some(let n): `Hello, ${n}`;
    when Option.None: "Hello";
  }
}

effect function report(id: string) {
  const outcome = try exit(getUser(id))
  return match (outcome) {
    when Exit.Success(let user): user.name;
    when Exit.Failure(let cause): Cause.pretty(cause);
  }
}

effect function getUser(id: string): { name: string }!NotFound!never {
  if (id === "") throw new NotFound({ id })
  return { name: "Ada" }
}
// Output: Hello, Ada
// Output: Hello
// Output: Ada
// Output: true
```

## Data variants

A [`data` declaration](/data-types/073-data) creates tagged values. Match their `_tag` with an object pattern. Variant constructors have no custom matchers:

```vibe
data Delivery {
  Waiting
  Sent { tracking: string; carrier?: string }
  Rejected { reason: string }
}

function track(delivery: Delivery) {
  return match (delivery) {
    when { _tag: "Sent", let tracking, carrier: "rail" }: `${tracking} by rail`;
    when { _tag: "Sent", let tracking }: `${tracking} by ${delivery.carrier ?? "post"}`;
    when { _tag: "Waiting" } or { _tag: "Rejected" }: "not sent";
    default: "unknown";
  }
}

function carrierOf(delivery: Delivery) {
  if (delivery is { _tag: "Sent" }) return delivery.carrier ?? "post"
  return "none"
}
// Output: ["parcel-8 by post","parcel-9 by rail","not sent"]
// Output: rail
```

A field in an object pattern takes a pattern, `carrier: "rail"`, or binds its value, `let tracking`. A bare `tracking` only tests that the property exists. A tag pattern narrows the subject as the corresponding TypeScript test does, so an arm may read the narrowed variant's other fields. A data type a `.ts` file declares with `Data.taggedEnum` matches the same way.

## Errors and custom matchers

An `error` class has a `Symbol.customMatcher` that tests `_tag`, so two classes with the same tag match each other; as an extractor it gives the instance: `when NotFound(let error):`. Class arms use the class's `Symbol.customMatcher`, independently of the subject's static type. A class without its own matcher, such as one imported from a `.ts` file, matches by `instanceof`: an object whose prototype was changed after construction no longer matches. A function that is not a class works as a predicate: `when isUser:` calls `isUser(value)` and narrows `value` as `if (isUser(value))` does, and `when Array.isArray:` tests for an array. A predicate must return a `boolean`; one that returns an Effect or a Promise is an error, so test it in a guard instead.

A value with a `[Symbol.customMatcher]` method decides for itself. `Symbol.customMatcher` comes from the proposal:

```vibe
const Even = {
  [Symbol.customMatcher](subject: unknown) {
    return typeof subject === "number" && subject % 2 === 0
  }
}

function parity(n: number) {
  return match (n) {
    when Even: "even";
    default: "odd";
  }
}
// Output: even, odd
```

For an extractor, the method receives `{ matchType: "extractor" }` as its second argument and returns `false` or the values to match against the list. Any other value matches when it is equal, with `NaN` matching `NaN`.

## Combining patterns

`and` requires both patterns, `or` accepts either, and `not` rejects its pattern. A guard, `if (condition)`, tests any expression and sees the bindings before it:

```vibe
function classify(job: { status: string; attempts: number }) {
  return match (job) {
    when { status: "failed", attempts: let n } and if (n >= 3): "escalate";
    when { status: "failed" }: "retry";
    when { status: not ("done" or "cancelled") }: "running";
    default: "leave";
  }
}
// Output: ["escalate","retry","running","leave","leave"]
```

`and`, `or`, and `not` cannot share a level: write `(a and b) or c`, not `a and b or c` (EK4705). An `or` or `not` pattern may bind names under the pinned TC39 binding rules. A name bound in every `or` alternative gets the union of its types.

## is

`value is pattern` is `true` when the pattern matches. It binds as tightly as `instanceof`:

```vibe
function isRetryable(failure: Failure) {
  return failure is Timeout or Denied
}
// Output: [true,true,false]
```

`is` may bind names in any expression. The current compiler still reports an `is` with bindings outside an `if` or `while` condition as EK4703. A binding is visible in the nearest block, including an `if`'s `else` branch and the code after the statement. It stays in the temporal dead zone until its binding pattern executes. Reading it before then throws `ReferenceError`. A following `&&` condition can use initialized bindings:

```vibe
effect function firstFailure(id: string) {
  const outcome = try exit(getUser(id))
  if (outcome is Exit.Failure(let cause) && Cause.hasFails(cause)) {
    return Cause.pretty(cause)
  }
  return "ok"
}
// Output: ok
// Output: true
```

Loop bindings follow the pinned TC39 loop scopes. A `for` head scopes its bindings to the head and body, with per-iteration copies for `for-of`. The proposal gives `while` and `do-while` a head scope and per-iteration body scopes. Bindings are in the temporal dead zone on the first `do-while` iteration.

## Exhaustiveness

`match` is exhaustive for the specified finite cases. Without a `default` arm, `EK4701` checks a match when every normalized subject member is a supported finite case. These include literals, `boolean`, `null`, `undefined`, enums, data variants, `error` and `schema error` instances, `Option`, `Exit` and `Result` cases, retained Effect errors, and tagged members.

An object, interface or class instance is tagged when its `_tag` has a literal type or a union of literal types. Only `_tag` counts as a discriminant. Each tag literal is a case. An optional `_tag` also has an `undefined` case.

Only unguarded arms cover cases. Literal and enum-member patterns cover their cases. A bare `error` pattern or its one-binding extractor covers that error case. The fixed patterns above cover their cases with bare `let` arguments, or with bare `Option.None`. A retained error's bare or one-binding extractor also covers its case.

An object pattern such as `{ _tag: "Sent", let tracking }` covers its tag case only for members that declare every other tested property as required. Each other property test must be a bare key or a `let` binding. Members sharing a tag are checked separately. Only a bare binding covers the `undefined` case of an optional `_tag`.

`or` covers the union of its alternatives. `and`, `not`, regex, relational, array, built-in matcher and user-matcher patterns cover nothing. Add `default` when cases remain. Runtime matching continues to use the pinned TC39 rules.

Any subject member outside these checked kinds turns the check off. Examples include `string` or `number` without a literal type, `unknown`, `any`, `object`, an untagged array or class instance, or a type parameter that does not normalize to checked cases. Use a `default` arm, an arm that matches every value of its type, such as `when String:` over a `string`, or a bind-only arm such as `when let other:`, which matches whatever is left.

A missing case is a compile error, EK4701, `This match does not handle every case of {type}: {cases} is left.`:

```vibe
// expect-error: EK4701
type Phase = "draft" | "review" | "published"

function phaseLabel(phase: Phase) {
  return match (phase) {
    when "draft": "Draft";
    when "published": "Published";
  }
}
```

```text
error EK4701: This match does not handle every case of Phase: "review" is left.
```

For a data type, the message names the variants left:

```vibe
// expect-error: EK4701
data Shipment {
  Packed
  Shipped { carrier: string }
  Delivered
}

function shipmentLabel(shipment: Shipment) {
  return match (shipment) {
    when { _tag: "Packed" }: "packed";
  }
}
```

```text
error EK4701: This match does not handle every case of Shipment: Shipment.Shipped | Shipment.Delivered is left.
```

Each error tag in a finite union needs coverage:

```vibe
// expect-error: EK4701
error Missing { path: string }
error Other { code: string }

function describeError(failure: Missing | Other) {
  return match (failure) {
    when Missing: failure.path;
  }
}
```

```text
error EK4701: This match does not handle every case of Missing | Other: Other is left.
```

A `return`, `break` or `continue` in an arm's `do` reaches its enclosing function or loop, as from a `for…of` body: iterators the patterns opened close first. In an `effect` function a failure, or a `throw`, ends the function without closing them; use `scoped` for cleanup on every exit.

An arm that only binds the value, `when let other:`, matches every value, as `default` does, so a match that ends in one handles every case. A match that handles every case needs no `default`, and tests that reach every arm cover every branch. Its last arm is still tested like every other arm, with the same reads, without adding a branch. If a value from an unsound cast or `any` matches no arm, the match throws a `TypeError`.

## Errors

| Code | Cause | Fix |
| --- | --- | --- |
| EK4701 | A match without `default` misses a case of a finite union | Add an arm for each case left, or a `default` arm |
| EK4705 | `and`, `or`, and `not` at one level without parentheses | Add parentheses |

The pinned design gives an ordinary `is` expression's `let` and `const` bindings the enclosing block's scope, including both `if` branches and code after it. A name remains in TDZ until its binding pattern runs; a later pattern failure does not undo an earlier initialization. The implementation limits below still apply.

## Not yet supported

- `async match` and the proposal's regular expression and relational patterns.

Support for the new forms arrives with the compiler's VIP implementation. VIP-7 accepts the full TC39 proposal, including regular-expression patterns, relational patterns, and `async match`.

A `match` can end a `do` block: `do { match (0) { default: 2; } }` has the selected arm’s value, `2`.

`Date` patterns test `subject instanceof Date`, as other built-in constructor patterns do, so `Object.create(Date.prototype)` matches and a date from another realm may not.

## Effect tagged-error guards

Patterns for `Cause.NoSuchElementError`, `Cause.TimeoutError`,
`Cause.IllegalArgumentError`, `Cause.ExceededCapacityError`,
`Cause.AsyncFiberError`, `Cause.UnknownError`, `Schema.SchemaError`,
`Cron.CronParseError`, `PlatformError.PlatformError`, `SemVer.SemVerError`,
`Terminal.QuitError`, and `TextDiff.TextDiffError` call the module's
corresponding `is…Error` guard. Namespace import aliases work too.
These guards accept brand-carrying copies from another package installation
and reject objects carrying only `_tag`. In extractor mode they yield the
subject as one value: `when Cause.TimeoutError(let error): …;`.
An extractor with the wrong number of arguments does not match. A rest pattern captures the remaining extracted values.
