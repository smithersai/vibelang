# VIP-10: the `Users.find(id)` shorthand (denied)

**Status:** denied by Will, 2026-10-28. There is no shorthand: get the service, then call it.

```ts
const users = try Users
const user = try users.find(id)
// or
const user = try (try Users).find(id)

// Effect TS
const user = yield* (yield* Users).find(id)
```

## What was proposed

`try Users.find(id)` would look up `Users`, call `find` and run the result. It was allowed only for members that return an Effect (D552). Prior art: Effect 3's `accessors: true`.

## Why it was denied

It is ambiguous. Class statics collide with member names: for a service with a member `name()`, `Users.name` could be `Function.name` or the shorthand. The same holds for `key`, `length`, `prototype`, `defaultValue` and `Shape`. A rule could have banned those member names; the shorthand saves too little to justify one.
