# Duration

`Duration` represents a signed time span with explicit units, including positive and negative infinities. Use it for delays, timeouts, retry backoffs, and elapsed measurements instead of bare numbers whose unit is implicit.

| Category | Key APIs |
| --- | --- |
| Unit constructors | `nanos`, `micros`, `millis`, `seconds`, `minutes`, `hours`, `days`, `weeks`, `infinity`, `negativeInfinity` |
| Input parsing | `fromInput(x)` (`Option`), `fromInputUnsafe(x)` (throws on invalid input) |
| Unit extraction | `toMillis`, `toSeconds`, `toMinutes`, `toHours`, `toDays`, `toWeeks`, `toNanos` (`Option<bigint>`), `toNanosUnsafe` |
| Arithmetic & comparison | `sum`, `times`, `equals`, `isLessThan`, `isLessThanOrEqualTo`, `isGreaterThan`, `isGreaterThanOrEqualTo`, `format` |

## Constructing finite and infinite durations

```vibe
const small = Duration.nanos(750n)
const micro = Duration.micros(20n)
const polling = Duration.millis(250)
const budget = Duration.seconds(12)
const session = Duration.minutes(15)
const shift = Duration.hours(8)
const retention = Duration.days(3)
const fortnight = Duration.weeks(2)
const unbounded = Duration.infinity
const negative = Duration.seconds(-2)
// Run in an effect function:
//   {
//     const jsonValue = [String(try Effect.try(() => Duration.toNanosUnsafe(small))), String(try Effect.try(() => Duration.toNanosUnsafe(micro))), Duration.toMillis(polling), Duration.toSeconds(budget), Duration.toMinutes(session), Duration.toHours(shift), Duration.toDays(retention), Duration.toWeeks(fortnight), String(unbounded), Duration.toSeconds(negative)]
//     try Console.log(try Effect.try(() => JSON.stringify(jsonValue)))
//   }
```

```text
["750","20000",250,12,15,8,3,2,"Infinity",-2]
```

Unit constructors document scale directly at the call site, and `infinity` / `negativeInfinity` represent unbounded spans. Every unit is fixed length (`Duration.days(1)` is always 24 hours, not a calendar day across DST transitions).

```vibe
const milliseconds = Duration.millis(240)
const nanoseconds = Duration.nanos(240n)
const text = Duration.seconds(3)
const checked = Duration.fromInput("3 seconds")
// Run in an effect function: try Console.log(Duration.toMillis(milliseconds), String(try Effect.try(() => Duration.toNanosUnsafe(nanoseconds))), Duration.toSeconds(text), Option.isSome(checked), Option.isNone(Duration.fromInput("invalid" as Duration.Input)))
```

```text
240 240 3 true true
```

`fromInput` parses existing durations, numeric milliseconds, `bigint` nanoseconds, and duration strings into an `Option`; `fromInputUnsafe` throws on invalid input. Prefer explicit unit constructors when the unit is known statically.

## Extracting values in chosen units

```vibe
const delay = Duration.minutes(2)
Duration.toMillis(delay) // 120000
Duration.toSeconds(delay) // 120
Duration.toMinutes(delay) // 2
Duration.toHours(delay) // 1 / 30
Duration.toDays(Duration.weeks(1)) // 7
Duration.toWeeks(Duration.days(14)) // 2
Duration.toNanos(Duration.millis(3)) // Some containing 3000000n
Duration.toNanos(Duration.infinity) // None
// Run in an effect function:
//   {
//     const jsonValue = [Duration.toMillis(delay), Duration.toSeconds(delay), Duration.toMinutes(delay), Duration.toHours(delay), Duration.toDays(Duration.weeks(1)), Duration.toWeeks(Duration.days(14)), String(try Effect.try(() => Option.getOrThrow(Duration.toNanos(Duration.millis(3))))), Option.isNone(Duration.toNanos(Duration.infinity))]
//     try Console.log(try Effect.try(() => JSON.stringify(jsonValue)))
//   }
```

```text
[120000,120,2,0.03333333333333333,7,2,"3000000",true]
```

Standard `to*` converters return floating-point `number` values in the chosen unit. Because `bigint` cannot represent infinity, `toNanos` returns `Option.Option<bigint>` while `toNanosUnsafe` throws on infinite spans.

## Comparing durations

```vibe
const elapsed = Duration.seconds(9)
const budget = Duration.seconds(12)
Duration.isLessThan(elapsed, budget) // true
Duration.isLessThanOrEqualTo(elapsed, elapsed) // true
Duration.isGreaterThan(budget, elapsed) // true
Duration.isGreaterThanOrEqualTo(budget, budget) // true
Duration.equals(Duration.seconds(1), Duration.millis(1000)) // true
// Run in an effect function: try Console.log(Duration.isLessThan(elapsed, budget), Duration.isLessThanOrEqualTo(elapsed, elapsed), Duration.isGreaterThan(budget, elapsed), Duration.isGreaterThanOrEqualTo(budget, budget), Duration.equals(Duration.seconds(1), Duration.millis(1000)))
```

```text
true true true true true
```

Comparisons evaluate the underlying elapsed span regardless of how each value was constructed. Compare `Duration` values directly instead of down-converting them to numbers first.

## Adding and scaling durations

```vibe
const attempt = Duration.seconds(4)
const overhead = Duration.millis(500)
const total = Duration.sum(attempt, overhead)
const doubled = Duration.times(total, 2)
Duration.toMillis(doubled) // 9000

effect function waitBeforeRetry() {
  try sleep(doubled)
}
// Run in an effect function:
//   provide TestClock.layer() {
//     try TestClock.setTime(0)
//     const waiting = fork waitBeforeRetry()
//     try TestClock.adjust("9 seconds")
//     join waiting
//     try Console.log(Duration.toMillis(doubled), try Clock.currentTimeMillis)
//   }
```

```text
9000 9000
```

`Duration.sum` adds two spans and `Duration.times` scales a span by a factor, both returning new values. Pass the result directly to `try sleep(duration)` inside effect code.

## Converting and formatting

```vibe
Duration.format(Duration.millis(6250)) // "6s 250ms"
String(Duration.infinity) // "Infinity"
Duration.toNanos(Duration.millis(2)) // Some(2000000n)
// Run in an effect function: try Console.log(Duration.format(Duration.millis(6250)), String(Duration.infinity), String(Option.getOrNull(Duration.toNanos(Duration.millis(2)))))
```

```text
6s 250ms Infinity 2000000
```

Use `Duration.format` only for human-readable output. For calculations, storage, or wire formats, extract an explicit numeric unit.
