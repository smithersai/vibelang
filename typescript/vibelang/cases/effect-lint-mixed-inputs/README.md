The extra stock reference requires TypeScript 5.9.3 from docs/tools and Effect 4.1.0. Prepare the latter with `npm install --prefix typescript/.cache/effect-4.1.0 --no-audit --no-fund effect@4.1.0` from the repository root, or set `EFFECT_410_NODE_MODULES` to an existing install. Missing dependencies fail the witness; they are not compiler conformance gaps. The harness also compares the ordinary declaration twin under the runtime pin.
