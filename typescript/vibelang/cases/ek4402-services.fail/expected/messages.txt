Use the Path service:   Path.join(directory, name)
Provide it in main with NodeServices.layer from "@effect/platform-node", or BunServices.layer from "@effect/platform-bun".
Use the ChildProcessSpawner service:   ChildProcessSpawner.string(ChildProcess.make(command, args))
Use HttpClient:   HttpClient.get(url)
Provide it in main with FetchHttpClient.layer from "effect/http", or NodeHttpClient.layerUndici from "@effect/platform-node".
Use Effect's crypto services:   SecureRandom.randomBytes(size)
Provide it in main with NodeCrypto.layer from "@effect/platform-node", BunCrypto.layer from "@effect/platform-bun", or BrowserCrypto.layer from "@effect/platform-browser".
Use the Path service:   Path.resolve()
Use the FileSystem service:   FileSystem.makeTempDirectory()
FileSystem.makeTempDirectory creates a directory in it; nothing returns its path alone.
Use the experimental Process service:   Experimental.Process.hostname()
Provide it in main with ExperimentalNodeServices.layer from "vibelang-runtime/experimental/platform-node", or ExperimentalBunServices.layer from "vibelang-runtime/experimental/platform-bun".
Effect, VibeLang's standard library, has no service for it yet, so escape to TypeScript for now.
Import it in a module block or a .ts file, and use it there or in a hatch.
