# TC39 Proposals [Where Smithers stands on every active proposal]

Smithers is a TypeScript-derived language, so a standards-track proposal is the cheapest possible source of new syntax: adopting one costs a grammar patch that upstream will eventually make unnecessary, while inventing an equivalent costs the same patch forever. The decision ledger therefore records an explicit adopt-early list, and an explicit set of standing rejections.

This page states a position for every proposal currently at Stage 1, 2, 2.7, or 3.

Exactly one row below is marked **Adopted**. Smithers adds a single source form beyond TypeScript, and it is standards-track. Every other capability is expressed with ordinary TypeScript syntax.

Proposal list fetched from [`tc39/proposals`](https://github.com/tc39/proposals) on **August 23, 2026**. Stages move; re-check before relying on one.

## Status Vocabulary

| Status | Meaning |
| --- | --- |
| **Adopted** | part of the Smithers target language |
| **Committed** | accepted for adopt-early inclusion as its source contract matures |
| **Reserved** | deliberately not adopted, but the design accounts for it |
| **Rejected** | a standing rejection in the ledger |
| No position | the ledger takes no stance |

"No position" is the honest default. It means the proposal has not been considered, not that it was weighed and dismissed.

## Already Finished

Smithers depends on several Stage 4 proposals that no longer appear above: import attributes, JSON modules, iterator helpers, and explicit resource management (`using`). `using` is the one worth naming — it is the whole cleanup story, and how its disposal orders against a compiler-generated `!` early return is [not yet settled](/specification/control-flow).

## Not Standards-Track

Two items the ledger lists as TC39 policy have no proposal at any stage: `Reflect.panic` and a worker failure protocol. They are treated as design intent rather than as adoption.

Two more are recorded as rejected because the proposal itself is gone: Record & Tuple was withdrawn, and cancelable Promises never advanced.
