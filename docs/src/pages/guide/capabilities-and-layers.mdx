# Capabilities & Layers [Make dependencies visible and provide them by scope]

VibeLang models a dependency as a capability in a compiler-tracked requirement channel. A Context class defines and accesses a service; a base Layer packages an already acquired implementation into an environment.

## Define a Capability

```ts
import { Context } from "vibelang/context"

abstract class Mailer extends Context {
  abstract send(message: Message): Result<Receipt, MailError>
}
```

The class is both the service contract and its nominal key. Two Context subclasses with identical methods remain distinct capabilities.

## Use a Capability

```ts
function welcome(user: User): Result<Receipt, MailError> {
  const mailer = Mailer.context()
  const clock = Clock.context()
  const message = Message.welcome(user, clock.now())
  return mailer.send(message)
}
```

The inherited `context()` call returns the instance and adds the class to the enclosing function's inferred requirements. `welcome` requires `Mailer | Clock`.

## Requirement and Result Composition

```ts
function register(
  input: Signup,
): Result<User, CreateUserError | MailError> {
  const users = Users.context()
  const user = users.create(input).unwrap()
  welcome(user).unwrap()
  return user
}
```

The compiler propagates `Users`, `Mailer`, and `Clock` through the ordinary calls. `.unwrap()` propagates the Error variants; these are separate from the requirement channel.

## Build and Provide a Layer

```ts
import { Layer } from "vibelang/provider"

const Production = Layer.merge(
  Layer.succeed(Clock, SystemClock),
  Layer.succeed(Mailer, new SesMailer(credentials)),
  Layer.succeed(Users, new PostgresUsers(databaseUrl)),
)

Layer.provide(Production, async () => {
  const user = (await registerAsync(input)).unwrap()
  return user.id
})
```

A base layer is conceptually `Layer<Provides>`. It provides service instances; it does not acquire them or own their lifetime. A missing dependency is a compile error when the closure is known.

Acquire resources in ordinary code and make cleanup explicit with `using` or `defer` before constructing the Layer. Resource-building conveniences may be added later, but they are not part of the base Layer contract.

## Test With Layers

```ts
const Test = Layer.merge(
  Layer.succeed(Clock, TestClock.at("2026-08-20T12:00:00Z")),
  Layer.succeed(Mailer, RecordingMailer.make()),
  Layer.succeed(Users, InMemoryUsers.empty()),
)

Layer.provide(Test, () => {
  const user = register(fixture).unwrap()
  expect(RecordingMailer.sent).toHaveLength(1)
  return user
})
```

No module replacement or global clock patch is needed.

## Platform Capabilities

```ts
function loadConfig(): Result<AppConfig, FileError | InvalidAppConfig> {
  const fs = FileSystem.context()
  const text = fs.readTextSync("app.json").unwrap()
  return parseAppConfig(text)
}
```

Node, Bun, Deno, native, WASI, and tests can provide different implementations of the same platform contracts.

:::note Implementation status
The platform capability library exists as a programmatic POC under
`poc/src/platform`, not as a root-CLI feature. It provides `Clock`, `Random`,
`Console`, `Environment`, `FileSystem`, and `HttpClient` as Context classes, each
with a live implementation and a deterministic test double, plus `Layer` bundles
that provide all six at once. Its I/O operations are asynchronous and return
`Promise<Result<A, E>>`; every filesystem operation also has a synchronous twin
with a `Sync` suffix (`readText` / `readTextSync`), which is the form used above.
On a host where async Layer scopes fail closed — the Bun test host, per the
scope note below — every capability an async body needs must be resolved before
its first `await`.
:::

## Scope and Lifetime

`Layer.provide(layer, body)` keeps only the dependency environment active until `body` and the Promise returned by `body` settle. It does not discover, supervise, cancel, or join other Promise work. Every Promise started in authored `.vibe` must be awaited directly or consumed by a recognized combinator whose returned Promise is itself consumed; detached work is unavailable.

The Node prototype revokes at the Promise's actual state transition, before its queued reactions run. It accepts a Promise created during the body invocation (including an `async` function's Promise), while a pre-existing Promise must be wrapped as `async () => await existingPromise`. This is a lifetime adapter, not task ownership. Async Layer scopes fail closed on hosts without an equivalent synchronous settlement hook; the current Bun test host therefore exercises only synchronous Layer scopes.

Merge and nested-override precedence, cycle diagnostics, and requirement-environment lowering remain under design. Source semantics do not depend on whether the backend uses hidden parameters or a scoped environment.
