# Features [A tour of the language model]

Smithers starts from TypeScript-shaped source and adds compiler semantics where they make application behavior explicit and statically analyzable.

## Values, Errors, and Requirements

```ts
async function getUser(
  id: string,
): Promise<Result<User, NotFound | DbError>> {
  const db = Db.context()
  const log = Logger.context()
  const row = (await db.findUser(id))!
  if (row === undefined) throw new NotFound(id)
  const user = User.from(row)
  log.info(`loaded user:${id}`)
  return user
}
```

`Result<User, NotFound | DbError>` carries success and expected errors as an ordinary value. `Db.context()` and `Logger.context()` add requirements tracked by the compiler. Plain returns and Error throws are lifted inside Result-returning functions.

## Result and Error APIs

```ts
const profile = loadProfile(id).match({
  ok: profile => profile,
  error: error => error.match({
    NotFound: () => Profile.guest(),
    InvalidProfile: error => { throw error },
  }),
})
```

`Result` supplies transformation, recovery, propagation, and must-use checking. Ordinary Error subclasses receive stable identity plus helpers such as `is`, `matches`, `match`, and `rootCause`. [Learn more](/guide/typed-failures).

## Absence

```ts
const user = cache.get(id) ?? guestUser
```

Absence is an ordinary `T | undefined` union. Smithers adds no `Optional<T>`: TypeScript already expresses absence precisely, and keeping it distinct from `Result` costs nothing.

## Capabilities and Layers

```ts
import { Context } from "smthrs/context"

abstract class Clock extends Context {
  abstract now(): Instant
}

function createToken(): Token {
  const clock = Clock.context()
  return Token.make({ issuedAt: clock.now() })
}
```

Layers package already acquired implementations into dependency environments. Resource ownership stays in explicit `using` code. Requirements flow through callers until a Layer satisfies them. [Learn more](/guide/capabilities-and-layers).

## Control Flow

```ts
if (const user = cache.get(id); user !== undefined) {
  render(user)
}
```

Control flow is TypeScript's. The one addition is declarations in conditionals, adopted early from TC39. Cleanup uses TC39 `using`. [Learn more](/guide/control-flow).

## Comptime

```ts
import { comptime } from "smithers:comptime"

const schema = comptime(JSON.parse(embed("./routes.json")))
const Routes = comptime(deriveRoutes(schema))
```

`comptime` is an imported intrinsic, not a keyword. Evaluation is deterministic and dependency-tracked, and it may create types. [Learn more](/guide/comptime).

## Runtime Validation

```ts
type Signup = { email: string; age: number }
const SignupSchema = comptime(Schema.derive<Signup>())
const signup = SignupSchema.parse(input)!
```

Validation returns an ordinary Result. [Learn more](/guide/runtime-validation).

## Typed Asset and Foreign Imports

```ts
import config from "./config.json" with { type: "json", mode: "const" }
import systemPrompt from "./prompts/system.md" with { type: "text" }
import { hash } from "./simd.zig" with { type: "zig" }
```

All non-code and foreign-source inputs use import attributes. Custom comptime loaders can turn SQL, GraphQL, YAML, or another format into typed modules. [Learn more](/guide/asset-imports).

## Multiple Targets

TypeScript is the only compilation target. Platform operations are capabilities,
and `comptime.target` selects a Node, Bun, Deno, browser, or edge implementation
without emitting the unused ones. Near-native and Wasm targets were specified
once and have been withdrawn. [Learn more](/guide/platforms-and-targets).

## Async and Concurrency

Async fallible work returns `Promise<Result<A, E>>`. Authored `.sm` consumes Promises only with `await`; Promise instance chaining is banned.

```ts
const results = await Promise.all([
  loadProfile(id),
  loadActivity(id),
])
const [profile, activity] = Result.all(results)!
```

[Learn more](/guide/concurrency).

## Durable Execution

```ts
import { durable } from "smithers:flows"

const Build = durable(function Build(
  input: BuildInput,
): Result<Artifact, CompileError | PackageError> {
  const compiled = Compile.run({ source: input.source })!
  return Package.run({ code: compiled.code })
})
```

The compiler lowers the checked body without invoking it. Plan mode reads emitted IR and runs neither the Flow nor any Action. [Learn more](/guide/durable-execution).
