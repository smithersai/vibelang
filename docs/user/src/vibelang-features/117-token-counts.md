# Token counts

How many tokens an agent reads to write VibeLang, and how many a VibeLang program takes beside the Effect TypeScript it replaces.

An agent that writes VibeLang loads the skill first: its forms, rules and idioms, with a link to the page that owns each one. The `vibelang` npm package ships it at `node_modules/vibelang/skills/vibelang/SKILL.md`.

## Method

- **Tokenizer:** OpenAI's `o200k_base` encoding, through js-tiktoken 1.0.21. No Anthropic count is published: no verified offline tokenizer exists for current Claude models, and these docs do not estimate one.
- **Pages:** each file's exact, complete Markdown source, nothing stripped. This page is not counted.
- **Cheat-sheet pairs:** each entry's code blocks as the cheat sheet writes them, without the docs checker's `// run:` and `// Output:` lines. The sides are not normalized, and the table understates the difference: each VibeLang snippet is a complete, runnable function, while many Effect TypeScript snippets are fragments, with `yield*` outside the `Effect.gen` it needs, and none imports `effect`.
- **Script:** `docs/tools/token-counts.ts` in the VibeLang repository measures every number below. `bun docs/tools/token-counts.ts --check` fails when this page drifts from what it measures, and `--write` updates it.
