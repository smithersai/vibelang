Developers building `@effect/ui` applications in VibeLang previously had no dedicated Effect UI starter template, runnable full-stack or multi-host examples, or setup documentation covering `exactOptionalPropertyTypes` and Effect UI primitives. `create-vibelang --ui` now scaffolds a strict Vite + `@effect/ui` + `@effect/ui-kit` + `@effect/ui-devtools` starter with an async `Command.Service` counter and `Story`/`HtmlScene` tests, `examples/` now includes three verified Effect UI showcase apps (`effect-ui-domains` with shared `HttpApi` and `Query.Service`, `effect-ui-uploads` with switch-mode fiber cancellation and VIP-21 `effect function*` progress streams, and `effect-ui-snake` mounting one `.vibe` core to both `@effect/ui/html` and `@effect/ui-opentui`), `docs/user/src/setup/effect-ui.md` documents Effect UI in Vibe side-by-side with Effect TypeScript, and `site/src/index.mdx` and `README.md` feature both the interactive `/play` Playground and the Effect UI starter.
