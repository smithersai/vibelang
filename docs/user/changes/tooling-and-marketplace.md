Installing the Vibe editor extensions previously required manual VSIX packaging and lacked a native Zed extension, and native macOS and Windows binaries were only cross-built without end-to-end starter verification. The VS Code extension now ships a PNG icon, changelog, gallery metadata, and Marketplace/Open VSX publishing automation, `editors/zed/` provides a complete Zed extension with tree-sitter grammars and workspace-aware `vibelang --lsp --stdio` discovery, CI now exercises native starter builds and tests across Linux, macOS, and Windows, and `vibelang-typescript` now documents its TypeScript 7 programmatic API and `tsserver` boundaries alongside expanded integration test coverage.
