Visitors exploring VibeLang had to install the CLI locally before trying the syntax, compiler diagnostics, or Effect TypeScript output. The documentation site now includes an interactive browser playground at `/play` backed by a `GOOS=js GOARCH=wasm` in-memory compiler (`typescript/tsc/cmd/vibelang-wasm` and `scripts/build-playground-wasm.sh`) plus an instant zero-wait preview fallback, curated presets covering Effect UI components, services, structured concurrency, and pattern matching, shareable URLs, and live sandboxed previews.
