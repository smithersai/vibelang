Defining serializable tagged unions previously required hand-writing `Schema.TaggedUnion({ ... })` alongside a manual `type Name = typeof Name.Type` alias, and recovering specific error tags in `catch` required the verbose `e catch effect (err) => match (err) { when Tag: value; default: throw err; }` boilerplate. VibeLang now supports `schema data Name { VariantA; VariantB { field: Type } }` (VIP-74), lowering directly to Effect 4's `Schema.TaggedUnion` plus its companion `type Name = typeof Name.Type` with full VIP-15 field mapping, `match` exhaustiveness checking (`EK4701`), declaration emit, formatting, ESTree, and mapper projection, and concise tagged `e catch { when ... }` (VIP-75), evaluating VIP-7 pattern arms in effect context with automatic flow-narrowed residual error rethrow matching `Effect.catchTag`/`Effect.catchTags`.
