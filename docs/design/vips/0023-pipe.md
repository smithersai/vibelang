# VIP-23: the pipe operator `|>`

**Status:** accepted by Will, 2026-10-28, under his standing approval ("assume I accept now. I will interrupt you if I need to").

## Decision

```ts
const n = fetchUser(id) |> retry(%, policy) |> timeout(%, "1 second")
try n
```

- Its Effect TS is nested calls, with each topic evaluated once into a temporary: `const t1 = fetchUser(id); const t2 = retry(t1, policy); const n = timeout(t2, "1 second")`.
- `|>` is exactly TC39's Hack pipe operator, pinned to a dated snapshot of the proposal, like `do` (VIP-2) and `match` (VIP-7).
- `%` is the topic: the left side's value, evaluated once. The topic-versus-modulo grammar is TC39's, unchanged.
- Effect's `pipe(x, f, g)` function remains available through VIP-14.
- **Ambiguity: none beyond TC39's own grammar.**
- **Amended 2026-10-29: the pinned snapshot.** `|>` is pinned to `tc39/proposal-pipeline-operator` commit `5ac4dfd624e68b649e6f947885bf5ef67bac19f4`, the head on 2026-10-28 (UTC), vendored in [`tc39-pipeline-operator/`](tc39-pipeline-operator/README.md), as pattern matching is pinned. Decided by the agent on 2026-10-29 under Will's rule "when I state a principle, the agent derives the concrete rule and acts; I can override later" (decided detail 52).
