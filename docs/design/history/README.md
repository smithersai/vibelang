# Historical design documents

**Historical, not normative.** Nothing here is part of the VibeLang language. The language is what the accepted VibeLang Improvement Proposals in [`../vips/`](../vips/README.md) define, and the specification in [`../src/`](../src/000-intro.md) states it.

This directory keeps, as reference material:

- `src/`: the previous specification (chapters 1 to 30 and appendices A to C), from the 2026-10-29 rewrite, with later archival annotations. [Chapter 9](src/109-part1-ch09-handlers.md) links to the archived revision of the retired handlers chapter.
- `DECISIONS.md`: the previous decision log, `D1` through `D520`. The [later decision references](LATER-DECISIONS.md) summarize the surviving descriptions in the VIPs.

The archived diagnostic registry uses the old numbering. Some codes were retired and others were reassigned. See [Appendix B](../src/900-appendices.md#appendix-b-diagnostics) for current diagnostic codes and meanings.
