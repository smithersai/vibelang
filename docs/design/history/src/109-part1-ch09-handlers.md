### 9. Handlers: defining your own effects

> **Retired handler design.** The first release has no handlers or continuation kernel. `control`, `handle`, `resume`, `abandon` are not supported. [VIP-35](../../vips/0035-handlers-open.md) remains an open proposal; any handler examples and machine descriptions below record the old prototype.

The previous handler tutorial is preserved in the [historical source](https://github.com/smithersai/vibelang/blob/90a26cf8e027473d4a360084b547fbe8246910d0/docs/design/history/src/109-part1-ch09-handlers.md). It does not describe supported VibeLang syntax. Use a `service` and `provide` for dependencies in this release.
