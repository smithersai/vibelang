Node 22.22.3 replaces the Node 26 package floor

No published VibeLang package needs a Node 26-only API. The binding limit is a Node loader bug: imported CommonJS requiring the synchronous ESM runtime bridge fails on Node 22.22.2 and earlier. Node 22.22.3 includes the relevant cache and loader-hook fixes; Node 24 needs 24.11.1 or later. The optional build graph retains its external tooling's fixed Node 26.4 declaration. Optional Web Locks still needs Node 24.5.
